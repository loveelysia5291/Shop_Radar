## Activity 直接綁定返回動作（已收入上述 Debug）

- MainActivity 在 `onCreate` 直接將唯一的畫面返回 callback 註冊到自己的 `onBackPressedDispatcher`，綁定 Activity 生命週期；Compose 不再另外尋找／註冊 dispatcher owner，只發布目前的返回動作。

## 蝦皮登入

右上角「登入蝦皮」直接開啟 https://shopee.tw/buyer/login，使用 Android 系統選定的 WebView（部分裝置由 Chrome 提供）。保留預設 User-Agent，啟用 JavaScript、DOM storage、viewport、輸入焦點與鍵盤縮放，蝦皮頁允許第三方 Cookie。

更多選單可查看目前 WebView 套件／版本、手動重開登入頁，或使用系統瀏覽器備援。系統瀏覽器與 App WebView 不共享登入狀態。App 不擷取帳密或表單；僅在本機檢查官方登入 Cookie 是否可用，不上傳或匯出，需在手機實測。

## 競拍追蹤

1. 進入「競拍」，填入 Yahoo 公開競標帳號 ID（出價紀錄中的 Y 加數字），按儲存。
2. 貼上 `https://tw.bid.yahoo.com/item/101764768005` 這類競拍網址，按訂閱競拍。
3. 允許通知；目前價、最高出價者、結標時間、倒數與上次成功查詢時間會顯示在卡片。

使用免登入 HTTPS 公開頁的 `isoredux-data` → `item.bidInfo`，不使用 WebView 的登入 Cookie。已實際驗證範例商品可匿名讀取 currentPrice、endTime、highestBidders、totalBids。公開欄位不是保證長期穩定的 API。

只在先確認自己的完整公開 ID 領先，後來變成其他公開 ID 領先時產生超標提醒；第一次看到其他人領先時，若完整公開出價紀錄可以證明自己曾領先後被超過，也可提醒。出價未超過對手、匿名遮罩、不完整回應、逾期頁面與網路失敗不會假設自己曾重新領先。暱稱可能重複，故使用公開 ID。確認後不重複同一輪提醒。

App 前台每 20 秒檢查未結束的競標，不會因切換頁面建立額外輪詢。背景刷新仍需由每筆競拍的「⋮」啟用並設定間隔，受睡眠模式與系統省電限制。網站自動延長競拍會於下次檢查更新倒數；到達快取結標時間會提示待確認，不能直接視為已結標。App 不自動出價。
